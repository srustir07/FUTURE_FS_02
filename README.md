# BizFlow Enterprise CRM 🚀

A professional, responsive Mini CRM (Lead Management System) built for tracking and managing business client relationships efficiently. Developed with a clean, enterprise-grade aesthetic.

## 🛠️ Tech Stack
* **HTML5** - Structure and semantic markup
* **CSS3** - Custom enterprise styling, CSS variables, and responsive grid/flexbox layouts
* **JavaScript (ES6+)** - Core application logic, local storage persistence, and form validation
* **Chart.js** - Dynamic, real-time visual analytics for lead distribution and deal values

## ✨ Key Features
* **Lead Tracking & Management:** Add, update, and manage leads with detailed information (Company, Email, Phone, Service, Deal Value, and Priority Level).
* **Follow-Up Management:** Track important client action items and upcoming follow-up dates.
* **Statistical Dashboards:** Real-time visual metrics powered by Chart.js showcasing pipeline data.
* **Data Persistence:** Automatically saves and syncs all lead data securely using browser `localStorage`.
* **Data Export:** Instant CSV export functionality for reporting and external backup.
